# Divyanshi Agarwal — Personal Portfolio

A personal portfolio website built using HTML, CSS, and JavaScript.

## Live Website

[Visit My Portfolio](https://divyanshia294-bot.github.io/divyanshi-portfolio/)

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Features

* Personal introduction and project cards
* Search projects by name or technology
* Light/Dark mode toggle
* Links to GitHub projects
* Contact section

## How to Run Locally

1. Download or clone this repository.
2. Open `index.html` in a web browser.
